# ADR-0003: 既存の決定論的ツールを先に借りる

**ステータス：Accepted**

## 目的と権威範囲

既存の決定論的EDAツールを初期実装で優先する判断を記録します。

## 文脈

READMEのロードマップは、初期に`kicad-cli`、freerouting、KiCadライブラリ、ソーシングAPIを使い、自前WASMエンジンやルーターは後回しにする。

## 決定

ACDはまず既存の決定論的検証・出力・配線ツールを型付きツールとして呼び出す。独自エンジンは、実機で回る細いループと回帰評価が確立した後に、明確な性能・互換性の根拠がある場合だけ検討する。

## 結果

初期の実装範囲を抑え、合否の再現性と製造互換性を優先できる。外部ツールのバージョン差、ライセンス、インストール環境はリスクとして記録する。
