# ADR-0002: 型付き設計グラフを正規モデルとする

**ステータス：Accepted**

## 目的と権威範囲

設計グラフを正規モデルとする判断の根拠と、投影の境界を定義します。

## 文脈

READMEは、回路図を正ではなく、要件からネットリスト・レイアウトまでの型付き設計グラフを正とする。AIが意図を扱い、決定論的ツールが投影を検証するには、差分可能な機械モデルが必要である。

## 決定

ACDの正規モデルを、出所・不確実性・設計根拠・検証結果を参照できる型付き設計グラフとする。回路図、KiCad、Gerber、FWはグラフから生成される投影・出力とする。

## 結果

回路図レスを既定にでき、再生成、差分、監査、複数出力が可能になる。回路図の書き込み・完全な往復変換は弱く、取込時は変換損失を明示する。
