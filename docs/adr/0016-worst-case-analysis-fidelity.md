# ADR-0016: ワーストケース解析の位置づけ

**ステータス：Proposed（未決定）**

## 目的と権威範囲

ワーストケース解析を公称値解析とシミュレーション忠実度ラダーのどこに位置づけるかの
候補を記録する。本ADRは提案であり、実装の前提にしてはならない。

## 文脈

公称値解析は代表値での成立を確認するが、部品特性、環境、許容差、経年などの変動を
十分に表さない場合がある。ワーストケース解析を追加すると実行コストが増えるため、
影響範囲がunknownのときにコストを理由として検証を狭めない規則との整合が必要である。
ルール評価の有効域は[ADR-0011](0011-three-valued-rule-evaluation-and-validity-domain.md)
の候補に依存する。

## 決定

ワーストケース解析を公称値解析との関係、忠実度、適用リスクに基づいて配置することを
提案する。まだ決定していない。コストだけを理由に必要な解析を省略せず、unknown影響が
残る場合はより広い検証へ進める。

## 代替案

- **(a) 公称値解析と同じゲートで条件違いとして扱う**：運用を単純化できるが、追加解析の
  実行条件とEvidenceが公称値結果に埋もれやすい。
- **(b) 上位の忠実度レベルとして分離する**：解析の深さと再利用条件を明確にできるが、
  追加gate、tool、モデル、再検証範囲が必要になる。
- **(c) 高リスク項目に限定した追加解析とする**：コストを抑えられるが、高リスクの判定と
  unknown影響の扱いを別途決定しなければならない。

## 判断基準

実行コスト、解析の再現性、入力条件とモデルの適用域、結果のstale伝播を比較する。
`verification-gates.md`の「コストを理由にした縮小は影響範囲がunknownの場合には認めない」
規則と整合し、unknown時に検証を広げることをfixtureと実行時間のEvidenceで確認する。
高リスク項目、公称値成立、変動を含む結果を同じ入力から再生して決定する。

## 結果とリスク

ワーストケース解析の位置づけを定めれば、公称値成立だけでは閉じないリスクを明示できる。
一方、解析時間、モデル適格性、入力データの不足が停止を増やす。候補フェーズはPhase 2
（検証と設計根拠）での評価とする提案であり、READMEのフェーズ境界を変更しない。unknown
見直し条件は、unknown影響を理由にした検証縮小、適用域外の結果流用、stale伝播の欠落が
見つかった場合とする。
