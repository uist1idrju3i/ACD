# ADR-0001: 技術判断をADRとして記録する

**ステータス：Accepted**

## 目的と権威範囲

ACD開発の技術判断を、後続の実装とエージェントが参照できる権威ある記録として残します。

## 文脈

ACDはAIエージェントと長期間協働して作るため、会話の記憶だけでは設計判断が失われ、同じ検討を繰り返す。READMEの「設計判断はADRとして残す」に従い、リポジトリを共有する正とする。

## 決定

技術選定、外部境界、スキーマ、永続化、互換性に関する判断を`docs/adr/`へ追記する。ADRは理由、代替案、前提、結果、撤回条件を持つ。

## 結果

エージェントはチャット履歴ではなくファイルを参照できる。後続判断は既存ADRを参照し、変更は新しいADRで記録する。
