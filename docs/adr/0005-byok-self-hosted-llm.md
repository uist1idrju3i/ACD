# ADR-0005: BYOKとセルフホストLLMを第一級にする

**ステータス：Accepted**

## 目的と権威範囲

LLMの利用形態、設計データの機密性、プロバイダ依存を扱う方針を定義します。

## 文脈

基板設計は機密性が高く、LLMのプロバイダ依存や学習利用を避けたい利用者もいる。READMEのロックインなし、出所、機密設計データ分離の原則に合致する必要がある。

## 決定

利用者自身のAPIキー（BYOK）とセルフホストLLMを第一級の実行形態とする。クラウドLLMを使う場合も、送信データ、保持、プロバイダ、同意を明示し、決定論的検証をLLMの出力から分離する。

## 結果

利用者の選択肢とデータ管理を維持できる。モデルの能力差、秘密管理、コスト、ローカル推論の性能は未決定であり、実装時に評価する。
