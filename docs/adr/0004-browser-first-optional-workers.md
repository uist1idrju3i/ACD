# ADR-0004: ブラウザ優先、ワーカーは任意

**ステータス：Accepted**

## 目的と権威範囲

ブラウザと任意ワーカーの責務分担を、実装の前提として定義します。

## 文脈

READMEはブラウザネイティブ、インストール不要を掲げる一方、長時間実行、高忠実度解析、大規模配線にはローカルまたはサーバーのワーカーが必要になり得る。

## 決定

UIと正規の型付き契約はブラウザを第一に設計する。軽量検証と状態閲覧はブラウザで行い、重い・長い・秘密性の高い処理は任意のローカル／サーバーワーカーへ委譲できる。両モードは同じ設計グラフ、ゲート、イベント契約を使う。

## 結果

導入障壁を下げつつ、セルフホストと長時間実行を可能にする。ワーカーのキュー、認証、同期方式、委譲単位は未決定であり、ADRで後続決定する。
